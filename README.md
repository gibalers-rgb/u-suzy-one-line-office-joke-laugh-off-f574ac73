A program that writes one original one-line office joke to `/output/entry.txt`. It holds four hand-written jokes, grades each against the judge's own rubric (on-subject, sharp punchline, instant landing, freshness, tight wording), and writes the winner. The winning line:

> I told HR my work-life balance was off, so they moved my desk next to the window — now I can watch the life I'm missing.

(HR "solves" the complaint literally: a window onto the life outside. "Watch" makes the punch active — the desk move is the punchline.)

## Run it

```sh
node main.ts
```

Writes `/output/entry.txt` (120 characters, one line) and verifies it against the gate (1–200 characters, not only whitespace, single line) before exiting, then reads the file back to confirm it matches byte for byte.
